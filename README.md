⌨️ Practiqué diversas etiquetas HTML en VS Code mientras seguía el tutorial. Aquí están las etiquetas principales que aprendí:

🏗️ Estructura Básica:

- **<!DOCTYPE html>** Define el tipo de documento
- **Html** Contiene toda la página
- **<head**> Sección inicial del documento
- <**title**> Define el título de la página
- <**body**> Contiene el contenido principal

📝 Elementos de Contenido:

- <**h1**> a <**h6**> Encabezados de diferentes niveles
- <**p**> Para crear párrafos
- <**br**> Inserta saltos de línea

🖼️ Elementos Multimedia:

- **<a href="URL"**> Enlaces a imágenes u otros recursos
- **<img src="imagen.jpg" alt="Descripción">** Insertar imágenes
- <**hr**> Crea líneas horizontales divisorias

📋 Elementos de Formulario:

- <**form**> Crear formularios
- <**input**> Campos de entrada
- <**textarea**> Áreas de texto extenso
- <**button**> Botones interactivos
